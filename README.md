# homebrew-the-pit

Homebrew tap for [The Pit](https://github.com/OscillatingMonkey/the-pit), an encrypted local secrets vault.

```sh
brew install oscillatingmonkey/the-pit/the-pit
```

`brew upgrade the-pit` picks up new releases. `brew install --HEAD oscillatingmonkey/the-pit/the-pit` builds the current `main`.

The formula is updated by `scripts/release` in the main repository. Report issues there.
